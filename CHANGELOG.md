# Changelog

Release notes are maintained in versioned files under `docs/`.

## 0.12.0

- Add three PF2e spell history and evidence-bound reconciliation tools, bringing MCP discovery to 63 tools.
- Add a bounded Bridge Spell audit panel that uses the existing GM approval queue and session-scoped automatic-write authorization.
- Preserve original cast/resolution records during reconciliation; append evidence to a separate GM-restricted world ledger.
- See [release notes](docs/release-v0.12.0.md), [operator guide](docs/spell-history-recovery.md), and [validation](docs/validation-v0.12.0.md).

## 0.11.0

- Add native PF2e spell attack, save, and base-damage resolution tools. See [v0.11.0 release notes](docs/release-v0.11.0.md).
